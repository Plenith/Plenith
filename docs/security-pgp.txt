Key rotation policy
-------------------

Annual rotation recommended. When rotating:
  1. Generate the new key BEFORE revoking the old one
  2. Publish both keys (with overlap period) for at least 90 days
  3. Update SECURITY.md, this file, the website, and keybase
     simultaneously
  4. Revoke the old key only after the overlap period
  5. Log the rotation in docs/IMPACT/ or the maintainer-org's
     key-rotation log

If a key is suspected compromised, revoke immediately, publish
the revocation certificate, and notify recent reporters who may
have used the compromised key.
